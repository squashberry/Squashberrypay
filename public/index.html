FAQ

Questions businesses and customers usually ask.

Does a customer need a SquashberryPay account?

No. Customers use the temporary payment page created by the business.

Can one payment code work in another app?

No. The verification system checks the exact business application, customer identity and payment before accepting a code.

How long does a payment page last?

The private checkout session lasts 60 minutes. The actual payment attempt begins when the customer opens the payment details and is limited to the configured attempt window.

How long does a verification code last?

By default, the one-time payment code remains valid for 24 hours and can be redeemed only once.

Can businesses have more than one app?

Yes. A business can create multiple applications inside its SquashberryPay account and manage them separately.

Can I use Pay Now, Subscribe and Donate?

Yes. Products can be configured as one-time purchases, subscriptions or donations.
